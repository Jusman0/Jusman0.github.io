Projects

One network, five ways down to the metal.

Each project builds on the one before it, and every result is checked bit-exact against a Python golden model.

  1. 01

    analog-neuron

    A neuron's weighted sum done by resistors. Kirchhoff's current law does the multiply-accumulate on a breadboard.

    ≤ 2.3 ADC steps from ideal
  2. 02

    tinyml-mnist-uno

    The MNIST network above, trained in PyTorch, quantized to int8 and run on an ATmega328P with 2 KB of SRAM.

    30.7 ms per image · 96.5%
  3. 03

    dp4a-unit

    NVIDIA's DP4A in Verilog: four int8 multiplies into a 32-bit accumulator per operation, every sign mode.

    10,000 / 10,000 bit-exact
  4. 04

    tiny-tensor-core

    The whole network in hardware: 32 MAC lanes, integer requantization, argmax. Placed and routed on an ECP5.

    273 clocks per image
  5. 05

    int8-rollout-engine

    The planner at the top of this page, in Verilog. An 8-lane build runs on a Tang Nano 20K FPGA, hardware-in-the-loop.

    4,000 / 4,000 decisions bit-exact
