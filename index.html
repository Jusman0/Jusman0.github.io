About

I build small neural-network hardware in Verilog and check it bit for bit against a Python model.

Most of my projects follow one operation, the weighted sum, from a resistor circuit to an Arduino, to custom int8 hardware on an FPGA. Each repo lists its results along with the commands I used to get them.

Verilog, Icarus Verilog, Yosys, nextpnr, Python, NumPy, PyTorch, Arduino, CUDA (CuPy), Tang Nano 20K

Projects

  • 01

    int8-rollout-engine

    A 32-lane int8 Verilog engine that plans actions for a pendulum. At each control step it runs 32 candidate plans through a small learned model and picks the one with the lowest cost.

    Matches the Python model on 4,000 / 4,000 decisions at 1,281 clocks each. An 8-lane build on a Tang Nano 20K FPGA is also bit-exact and takes 186 µs per decision.

    DemoGitHub
  • 02

    tiny-tensor-core

    My int8 MNIST network from tinyml-mnist-uno, implemented in Verilog with 32 parallel multiply-accumulate lanes and integer-only rescaling between layers.

    Bit-exact on all 10,000 MNIST test images, with the same predictions as the Arduino version. 273 clocks per image, about 50 MHz on an ECP5 FPGA.

    DemoGitHub
  • 03

    dp4a-unit

    A Verilog implementation of DP4A, which multiplies four pairs of int8 values and adds the products to a 32-bit accumulator in one operation.

    Bit-exact on 10,000 / 10,000 test vectors. The two-stage pipelined version reaches 88.5 MHz on an iCE40 HX8K, up from 51.6 MHz.

    GitHub
  • 04

    tinyml-mnist-uno

    A handwritten-digit classifier trained in PyTorch, quantized to int8, and run on an Arduino UNO, which has 2 KB of SRAM and no floating-point unit.

    6,634 parameters, 96.5% on the MNIST test set, 30.7 ms per image on the UNO.

    GitHub
  • 05

    analog-neuron

    A neuron's weighted sum computed by a resistor network on a breadboard, read by an Arduino UNO and compared with the same sum computed digitally.

    Stage 1 reads within 2.3 ADC steps of the predicted values. Stage 2, a weighted neuron with an op-amp activation, is designed but not built yet.

    GitHub
  • 06

    hackforge

    A Claude Code plugin for hackathons: research, idea scoring against the event's rubric, a build loop with a separate QA agent, mock judging, and a fact-checked submission.

    12 skills, 8 agents, 4 hooks and 5 workflows, with three steps where you approve before it continues.

    GitHub
  • 07

    ultrasonic-proximity-alarm

    An Arduino UNO with an HC-SR04 ultrasonic sensor and a buzzer that sounds when something comes too close.

    I lost the original sketch and rebuilt it from the demo video, choosing the distance formula that matches all 19 logged readings.

    GitHub
