The network is the one from my Arduino project: 196 inputs, 32 hidden units, 10 outputs, with int8 weights. The Arduino rescales between layers with floats. The Verilog version uses one fixed-point multiply and a shift instead:

layer 1 acc1[j] = sum of W1[j][i] * x[i] 197 clocks rescale h[j] = clamp((acc1[j] * 31942 + B1q[j] + 2^23) >> 24, 0, 127) 32 clocks layer 2 acc2[k] = sum of W2[k][j] * h[j] 33 clocks pick digit = argmax(acc2[k] + B2q[k]) 11 clocks

This page runs that integer math in JavaScript. It matches the Python model on every hidden value and every prediction for all 10,000 MNIST test images. On an ECP5 FPGA the design runs at about 50 MHz, about 5.5 µs per image. The Arduino UNO takes 30.7 ms.

Your drawing is prepared the way MNIST digits are: scaled to fit a 20 × 20 box, centred in 28 × 28, then averaged down to 14 × 14.
